========================================
CARA MENGATASI ERROR DI BROWSER
========================================

ERROR SUDAH DIPERBAIKI DI CODE!
Tapi browser masih load file lama dari cache.

LANGKAH-LANGKAH:
========================================

OPTION 1 - HARD REFRESH (CEPAT):
1. Buka browser
2. Tekan Ctrl+Shift+R (atau Ctrl+F5)
3. Tunggu page reload
4. Error HILANG!

OPTION 2 - CLEAR CACHE (LEBIH BERSIH):
1. Buka browser
2. Tekan Ctrl+Shift+Delete
3. Pilih "Cached images and files"
4. Klik "Clear data"
5. Refresh page (F5)
6. Error HILANG!

OPTION 3 - RESTART VITE (PALING BERSIH):
1. Stop Vite server (Ctrl+C di terminal)
2. Jalankan: CLEAR_CACHE_AND_RUN.bat
3. Tunggu Vite start
4. Hard refresh browser (Ctrl+Shift+R)
5. Error HILANG!

========================================
KENAPA ERROR MASIH MUNCUL?
========================================

Browser cache masih menyimpan file JavaScript lama
yang punya bug template literal:
  `text-${color}-600` ❌ (SALAH - sudah diperbaiki)
  
File baru sudah pakai:
  data-[selected=true]:text-green-600 ✅ (BENAR)

Setelah clear cache, browser akan load file baru
dan error HILANG!
